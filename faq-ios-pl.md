**Wykorzystanie SDK w aplikacji React Native**

Jeśli chcesz, możesz używać SDK w aplikacji napisanej w React Native. Wystarczy, że (tak jak w przypadku każdej innej biblioteki natywnej) udostępnisz interesujące Cię klasy i metody do wykorzystania w projekcie React Native pisząc odpowiednie wrappery.
