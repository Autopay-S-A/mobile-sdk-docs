# O wtyczkach Autopay

**Wtyczki Autopay** to gotowe integracje płatności dla najpopularniejszych silników e-commerce. Pozwalają szybko i bez pisania własnej integracji od zera uruchomić w sklepie internetowym płatności obsługiwane przez Autopay (m.in. BLIK, karty płatnicze, przelewy online, Google Pay, Apple Pay).
