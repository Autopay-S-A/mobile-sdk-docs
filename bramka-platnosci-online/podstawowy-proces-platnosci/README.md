# Podstawowy proces płatności

Podstawowy proces obejmuje [rozpoczęcie transakcji](start-transaction.md), [powrót klienta do serwisu](customer-redirect.md) oraz [obsługę statusu transakcji i ITN](transaction-status-and-itn.md).

Możesz rozszerzyć ten proces o [zaawansowaną integrację](../../integracja-whitelabel/whitelabel.md): wybór metody płatności po stronie merchanta oraz widgety kartowe i Visa Mobile. Wspólne specyfikacje pozostają w odpowiednich działach dokumentacji bramki.
