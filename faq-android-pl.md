# faq android pl

**Wykorzystanie SDK w aplikacji React Native**

Jeśli chcesz, możesz używać SDK w aplikacji napisanej w React Native. Wystarczy, że (tak jak w przypadku każdej innej biblioteki natywnej) udostępnisz interesujące Cię klasy i metody do wykorzystania w projekcie React Native, pisząc odpowiednie wrappery.

**Wykorzystanie SDK w aplikacji Flutter**

Jeśli chcesz, możesz używać SDK w aplikacji napisanej w Flutter. Wystarczy, że (tak jak w przypadku każdej innej biblioteki natywnej) udostępnisz interesujące Cię klasy i metody do wykorzystania w projekcie Flutter, pisząc odpowiednie wrappery.

Pamiętaj, żeby tworząc wrappera nie umieszczać widoków SDK jako jedyne dziecko w `ScrollView`. Może to spowodować, że widok nie będzie widoczny.

**Wykorzystanie SDK w aplikacji wspierającej wiele języków**

Jeśli chcesz użyć SDK w aplikacji wspierającej różne języki, odpowiednie informacje znajdziesz w [**Dokumentacja Android**](/broken/pages/f04eeb6b22aea95f271aef62f2ac4e787c8b83de#jesli-jezyk-domyslny-aplikacji-jest-inny-niz-jezyk-domyslny-sdk).
